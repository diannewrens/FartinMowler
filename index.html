About the persona

Fartin Mowler is a parody software architecture commentator for the AI era. If every paradigm shift needs a sober pattern language, AI deserves one willing to admit the room smells weird.

This is satire, not impersonation. Any resemblance to respected software authors with better names and fewer digestive metaphors is part of the joke.
